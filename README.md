# Korean Web Design Guide

한국어 웹서비스의 랜딩, 제품 화면, 모바일 UI를 설계하고 리뷰하는 공개 가이드입니다. Codex와 Claude Code에서 같은 스킬을 사용할 수 있습니다.

**링크 하나로 시작하기**

> https://github.com/0-ki/korean-web-design-guide 참고해서 이 프로젝트의 화면을 디자인해 줘. 실제 한국어 콘텐츠로 모바일과 데스크톱을 확인해 줘.

이 요청을 받은 에이전트는 [스킬 본문](skills/korean-web-design/SKILL.md)을 읽고 대상 프로젝트에서 실행합니다. 파일 링크를 열 수 있는 환경이라면 설치 없이 시작할 수 있습니다. [원문 Markdown](https://raw.githubusercontent.com/0-ki/korean-web-design-guide/main/skills/korean-web-design/SKILL.md)
